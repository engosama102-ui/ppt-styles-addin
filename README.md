# 🎨 PowerPoint Styles Manager Add-in

Add-in لـ PowerPoint على Mac و Windows يتيح لك حفظ وتطبيق أنماط النص بسهولة.

## ✨ الميزات

- ✅ حفظ أنماط نص غير محدودة
- ✅ استيراد الأنماط من النص المحدد في PowerPoint
- ✅ تطبيق الأنماط بضغطة واحدة
- ✅ معاينة مباشرة للأنماط
- ✅ تصدير واستيراد الأنماط (JSON)
- ✅ تعديل وحذف الأنماط
- ✅ واجهة عربية كاملة
- ✅ يعمل على Mac و Windows

## 📦 التثبيت

### الخطوة 1️⃣: رفع الملفات على GitHub

1. أنشئ repository جديد على GitHub (مثلاً: `ppt-styles-addin`)

2. ارفع جميع الملفات للـ repository:
   ```
   ppt-styles-addin/
   ├── manifest.xml
   ├── src/
   │   ├── taskpane.html
   │   ├── taskpane.js
   │   └── commands.html
   └── assets/
       ├── icon-16.png
       ├── icon-32.png
       ├── icon-64.png
       └── icon-80.png
   ```

3. فعّل **GitHub Pages**:
   - اذهب إلى Settings → Pages
   - اختر Source: `main` branch
   - احفظ التغييرات
   - سيصبح الموقع متاح على: `https://YOUR-USERNAME.github.io/ppt-styles-addin/`

### الخطوة 2️⃣: تعديل ملف Manifest

افتح ملف `manifest.xml` وعدل الأسطر التالية:

1. استبدل `YOUR-GITHUB-USERNAME` باسم المستخدم الخاص بك على GitHub في جميع الأماكن:
   ```xml
   https://YOUR-GITHUB-USERNAME.github.io/ppt-styles-addin/
   ```

2. غيّر الـ `Id` إلى GUID فريد:
   - اذهب إلى https://www.uuidgenerator.net/
   - انسخ الـ GUID
   - استبدل `12345678-1234-1234-1234-123456789abc` بالـ GUID الجديد

### الخطوة 3️⃣: إنشاء الأيقونات

أنشئ أيقونات PNG بالمقاسات التالية وضعها في مجلد `assets/`:
- `icon-16.png` (16×16 بكسل)
- `icon-32.png` (32×32 بكسل)
- `icon-64.png` (64×64 بكسل)
- `icon-80.png` (80×80 بكسل)

💡 يمكنك استخدام أي أيقونة تحبها أو إنشاء واحدة بسيطة باستخدام:
- https://www.canva.com/
- أو أي محرر صور

### الخطوة 4️⃣: تثبيت الـ Add-in في PowerPoint

#### على Mac:

1. حمّل ملف `manifest.xml` المعدل

2. افتح **PowerPoint**

3. اذهب إلى **Insert** → **Add-ins** → **My Add-ins**

4. اضغط على **Manage My Add-ins** (أيقونة الترس)

5. اختر **+ Add a custom add-in** → **Add from file...**

6. اختر ملف `manifest.xml`

7. اضغط **Install**

#### على Windows:

1. ضع ملف `manifest.xml` في مجلد مشترك على الشبكة أو محلي

2. افتح **PowerPoint**

3. اذهب إلى **File** → **Options** → **Trust Center** → **Trust Center Settings** → **Trusted Add-in Catalogs**

4. أضف مسار المجلد الذي يحتوي على `manifest.xml`

5. اختر **Show in Menu**

6. أعد تشغيل PowerPoint

7. اذهب إلى **Insert** → **My Add-ins** → **Shared Folder**

8. اختر الـ Add-in من القائمة

## 🎯 كيفية الاستخدام

### حفظ نمط جديد:

1. **من النص المحدد:**
   - حدد نصاً في PowerPoint
   - افتح Add-in من الريبون (تبويب Home → "مدير الأنماط")
   - اضغط "📥 استيراد من النص المحدد"
   - سيتم استيراد جميع خصائص النص تلقائياً
   - أدخل اسماً للنمط واضغط "💾 حفظ النمط"

2. **يدوياً:**
   - افتح الـ Add-in
   - املأ خصائص النمط (خط، حجم، لون، إلخ)
   - شاهد المعاينة المباشرة
   - أدخل اسماً واضغط "حفظ"

### تطبيق نمط:

1. حدد النص الذي تريد تنسيقه في PowerPoint
2. افتح الـ Add-in
3. ابحث عن النمط المطلوب في القائمة
4. اضغط "✓ تطبيق"
5. سيتم تطبيق النمط فوراً!

### إدارة الأنماط:

- **تعديل:** اضغط "✏️ تعديل" → عدّل الخصائص → احفظ من جديد
- **حذف:** اضغط "🗑️ حذف"
- **تصدير:** اضغط "📤 تصدير" لحفظ نسخة احتياطية (JSON)
- **استيراد:** اضغط "📥 استيراد" لاستعادة أنماط من ملف

## 🔧 استكشاف الأخطاء

### الـ Add-in لا يظهر:
- تأكد من أن GitHub Pages مفعل وأن الملفات متاحة
- تحقق من أن جميع الروابط في `manifest.xml` صحيحة
- جرب حذف الـ Add-in وإعادة تثبيته

### خطأ في تطبيق الأنماط:
- تأكد من تحديد نص في PowerPoint قبل الضغط على "تطبيق"
- تحقق من Console في المتصفح (F12) للأخطاء

### الأنماط المحفوظة اختفت:
- الأنماط محفوظة في `localStorage` في المتصفح
- إذا مسحت بيانات المتصفح، ستختفي الأنماط
- استخدم "تصدير" بانتظام لحفظ نسخة احتياطية

## 📝 ملاحظات تقنية

- **Office.js API:** يستخدم PowerPoint JavaScript API
- **التخزين:** localStorage للمتصفح
- **التوافق:** PowerPoint 2016+ على Mac و Windows
- **الترخيص:** مفتوح المصدر
